## 🇺🇸 English

**Alıcısına** is a modern C2C (Consumer-to-Consumer) e-commerce platform where users can securely post advertisements, browse categories, and buy/sell second-hand items. This project is built using **ASP.NET Core MVC** architecture, following industry standards.

### 🚀 Key Features
* **User Management:** Secure registration, login, and logout processes using ASP.NET Core Identity.
* **Ad Management:** Users can create detailed product listings with image uploads.
* **Category System:** Products are organized into categories (Electronics, Vehicles, Home, etc.) for easy navigation.
* **Advanced Search:** Filter products by price range, category, or keywords.
* **Responsive UI:** Mobile-friendly interface designed with Bootstrap 5.

### 🛠️ Tech Stack & Architecture
This project follows the **N-Tier Architecture** principles.

* **Backend:** C#, ASP.NET Core MVC
* **ORM:** Entity Framework Core (Code First Approach)
* **Database:** SQLite (Dev) / PostgreSQL (Production ready)
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Tools:** Visual Studio, Git & GitHub

### 💻 Installation
1.  Clone the repository:
    ```bash
    git clone [https://github.com/Aytekseng/AlicisinaWebProject.git](https://github.com/Aytekseng/AlicisinaWebProject.git)
    ```
2.  Navigate to project directory:
    ```bash
    cd AlicisinaWebProject
    ```
3.  Update the database (Migrations):
    ```bash
    dotnet ef database update
    ```
4.  Run the application:
    ```bash
    dotnet run
    ```

## 🇹🇷 Türkçe

**Alıcısına**, kullanıcıların hızlı ve güvenli bir şekilde ürün ilanı verebildiği, kategorilere göre arama yapabildiği modern bir ikinci el alım-satım platformudur. Bu proje, **ASP.NET Core MVC** mimarisi kullanılarak, temiz kod prensiplerine uygun olarak geliştirilmiştir.

### 🚀 Özellikler
* **Kullanıcı Yönetimi:** ASP.NET Core Identity ile güvenli üyelik ve giriş işlemleri.
* **İlan Verme:** Kullanıcıların resim yükleyerek detaylı ürün ilanı oluşturabilmesi (CRUD).
* **Kategori Sistemi:** İlanların elektronik, vasıta, ev eşyası gibi kategorilere ayrılması.
* **Detaylı Arama:** Fiyat aralığına veya kelimeye göre ilan filtreleme.
* **Mobil Uyumlu Tasarım:** Bootstrap 5 ile her cihazda düzgün çalışan arayüz.
